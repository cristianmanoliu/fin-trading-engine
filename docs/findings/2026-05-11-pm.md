### Track 2: Python-side audit (commit `c1775a2`)


`vps` and `remote_dir` are operator-controlled (--vps, --live-dir).

Applied realized_cost_trajectory's fix to:

`scripts/test_remote_fetch_no_shell_injection.py` pins the fix two ways:
1. **AST scan** — no `subprocess.run(..., shell=True)` anywhere in the
   four target scripts. AST-based because substring search yielded
   false positives on legitimate comments (realized_cost_trajectory's
   inline "Avoid shell=True with f-string" lens-documentation comment)
   and error f-strings (`f"ssh fetch failed: {e}"`).
2. **Behavioural** — monkey-patch `subprocess.run`, drive each
   fetch_remote with an evil remote_dir containing `;` `$()` `"`,
   assert first call is list-form starting with "ssh" and the
   metacharacters aren't present unquoted in the remote command.

Bonus cleanup: dropped `["python3", str(path), "--quiet"] if False else ["python3", str(path)]`
dead conditional in `forward_paper_resolution.invoke_sibling`.

### Track 4: layer3_verdict synthetic rehearsal (commit `01d863a`)

Operator-path symmetry with Layer 2 (Track 1). Two real fail-opens
discovered + closed in `scripts/layer3_verdict.sh`:

- **F1 (HIGH severity)**: `cmd/journal_diff` returns exit 4 on Go panic
  (`recoverPanic` in main.go:279) AND can produce arbitrary codes on
  SIGSEGV (139) / OOM (137). The wrapper's dispatch explicitly handled
  `diff_exit ∈ {1,2,3}` but had no catch-all — anything else fell
  through to the duration → PASS branch. **A panic'd diff binary would
  have promoted a fundamentally-broken Layer 3 to STAGE_1 real-money.**
  Fixed with explicit `diff_exit==4` handler (PANIC → INPUT_ERROR) +
  catch-all `if [[ "$diff_exit" != "0" ]]` AFTER the documented
  branches → exit 3 with "unexpected exit code N" diagnostic.

- **F2 (MED severity)**: future-timestamp from clock skew yielded
  `elapsed_seconds < 0`, which routed to INSUFFICIENT_DURATION
  ("keep running and re-check") — wrong advice for input error.
  Fixed with explicit `elapsed_seconds -lt 0` guard → exit 3.

`LAYER3_VERDICT_DIFF_OVERRIDE` env hook mirrors today's
`LAYER2_SMOKE_INJECT_LOG` — env-var test hooks for exercising
subprocess-exit-code dispatch without rebuilding Go. **New pattern
emerging**: subprocess-exit-code-dispatch-catch-all family. Currently
1 instance (Track 4); will look for siblings.

Test count 9 → 20 (11 new tests covering panic / segfault / unknown
exits / override missing / precedence chains / unknown CLI flag).
