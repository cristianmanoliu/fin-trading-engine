## F1-F6: Script-layer audit pass (3 commits, 70 test assertions)

### F1 — run_drift_check.sh corrupt-history (commit `3b664f1`)

The wrapper read `drift_check_history.jsonl` through `jq` inside a
`set -euo pipefail` while-loop. A single malformed line (kill -9 mid-write,
disk-full, manual edit) aborted the wrapper with jq's parse exit code (~5),
bypassing the case→Telegram dispatch that only handles 0-4. weekly_audit
propagated the unmapped exit to launchd. **Decision-grade kill mechanism
silently dies on the only failure mode that matters.**

Fix:
- Per-line lenient parse with explicit MALFORMED counter
- New exit code 5 = HISTORY_CORRUPT routed to Telegram WARN with sample
  malformed entries embedded in the alert
- When MALFORMED > 0, suppress AUTO-KILL even if the rule would trip —
  cannot trust the rule against partial data
- Lenient pattern also applied to the bottom `tail -5 | jq` display path
- Env-overridable paths (DRIFT_CHECK_DETECTOR/HISTORY/RUNS_DIR) for testability

23 regression assertions in `scripts/test_run_drift_check.sh`. Bash test
infra wired into CI as a new `test_*.sh` loop step in the python-tests job
(auto-discovers future bash tests).

### F2-F5 — weekly_audit.sh tier classifiers + UNEXPECTED branches (commit `92b5772`)

**F2 — ssh-vs-validate misclassification.** ssh exit 255 (connection refused

**`033ed02` — marketdata: REST-poll-lag instrumentation.** Added
optional `LocalReceiptTS time.Time` field to `models.Tick`; set by
`BinanceFutures` producers (`wsLoop` + `processAggTradeBatch`) at

unaffected. `Heartbeat.Observe` captures lag = `LocalReceiptTS -

0-10s+ (poll interval = 10s). At Layer 2 testnet activation this lag
will manifest as fill-price drift; in paper today it would manifest
as gradual API degradation that the existing heartbeat (only tracking
last_tick_age) cannot distinguish from "low-volume symbol."

LocalReceiptTS = no lag), BinanceFutures path captures lag, ring

includes lag args when samples present, snapshotForLog omits lag_*
args when no samples. Full Go suite green.
