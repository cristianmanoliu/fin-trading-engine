## Patterns reinforced (already in audit_pattern_2026-05-09)

1. **Variant input shape** — when an upstream tool emits two formats
   for the same logical state ("cohort with closes" vs "cohort without
   closes"), the consumer must match both or invisibly drop one.
2. **Format-change drift** — regex-based parsers must fail loudly
   when no patterns match anywhere, not silently render empty.
3. **No data ≠ pass** — gates must distinguish "evaluated and
   satisfied" from "couldn't evaluate." `[PENDING]` ≠ `[PASS]`.
4. **Filter at the right layer** — exit-code decisions must run on
   the post-filter set, not the pre-filter set.
5. **Distinct exit codes for distinct shapes** — empty dir, no closes
   yet, all pre-decomp, qualifying-trades-present each get their own
   exit code so cron wrappers can route Telegram tiers correctly.
6. **None-safe coercion at JSON boundaries** — `dict.get(k, default)`
   only fires the default for KEY missing, not for present-but-null.
   `_num()` helper now standardizes the coercion across the script.
7. **Drop `shell=True`** — list-arg subprocess by default; if a remote
   shell is unavoidable, `shlex.quote` the interpolated paths.
