### 2. Lens-as-self-correction validated twice

### 3. Operator-action paths need the most aggressive lens

The cmd/kill_switch finding (`6dc3836`) was HIGH severity not because the bug shape was unusual — same silent-fallthrough as elsewhere — but because of **timing context**: the operator fires this CLI under maximum stress (post-drift-fire, panic kill of real-money positions), reads the output to confirm, then files the artifact. A green "All positions closed cleanly" message firing while there's residual exposure on Binance is the worst-case failure mode for any code path in the project. Fix added distinct exit code 2 for PARTIAL fills with explicit residual reporting.

**Lesson banked: any path operator-triggered under stress cannot have silent fallthrough. Distinct exit codes for distinct states; collapsing partial→success is the audit-pattern shape.**
