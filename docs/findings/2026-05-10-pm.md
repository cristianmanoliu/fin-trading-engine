## Three lens findings during T2a build (lens-as-self-correction Mode 3 catalog grew 2 → 5)

1. **Glob inside quoted variable expansion silently fails.** `/bin/ls "$pattern"`
   with `*` inside the variable: `ls` doesn't glob, shell can't expand a glob
   inside a quoted expansion. Standardized to `find` across all multi-file
   lookups.

2. **`grep "..." *.jsonl | python3` with `set -euo pipefail` crashes on zero
   match.** Phase 4's legitimate "no closes yet" state was triggering grep
   exit-1 → pipefail → script crash. Rewrote to pure python with
   `pathlib.glob` (empty list on no-match, not error).

3. **Locked decision-rule doc false-positive on phase1 gate check.** The
   locked `forward_paper_completion_review_decision_rule_2026-05-08.md`
   itself contains the literal `Composite verdict: ALL_GREEN` inside its
   template scaffold. My gate check matched the rule's DESCRIPTION rather
   than an actual verdict — phase1 happily created a real in-progress
   artifact in production results/. Fixed by excluding `_decision_rule_*` /
   `_template_*` / `_verdict_*` from gate-doc candidates. Regression test
   pins the fix.

Plus a 4th caught via shellcheck during the SSH-side rewrite:
**SC2259 heredoc-vs-pipe stdin collision** — `ssh ... | python3 - <<EOF`
would have silently broken the production read because the heredoc-as-stdin
overrides the piped stdin. Fixed via `python3 -c "..."` form.
